# Task Completed Archive

## Estructura
- Un archivo por mes: `YYMM.md` (ej. `2609.md` = septiembre 2026)
- Tareas agrupadas por fecha de completado

## Reglas
1. **Un archivo por mes** — todas las tareas completadas en ese mes van en un solo archivo
2. **Fecha cada sección** — agrupar por fecha de completado: `## YYYY-MM-DD: Descripción`
3. **Usar las claves de tarea** — referenciar la clave de TASK_TODO.md
4. **Detallar qué se hizo** — items completados como `- [x]` checkboxes, con el PR como evidencia
5. **Incluir contexto** — notas breves sobre decisiones y cambios
6. **Sin bloques de código** — referenciar rutas de archivo y nombres de función, no código
7. **Mover, no copiar** — quitar las tareas completadas de TASK_TODO.md al archivarlas aquí
8. **Preservar la fecha `added:`** — al archivar, mantener la fecha de creación original

Lo entregado antes de septiembre 2026 (PRs #1–#22) no tiene archivo mensual: está en
`CHANGELOG.md`, que en este repo ya cumplía ese papel.
